# Gemini handoffs

Gemini runs in the Gemini app (Brian's account), not from this repo, so
these files are ready to paste.

- **`ART-BRIEF.md`:** original art (empty-state illustrations, fallback
  game cards, the share-image background). Save the results to
  `apps/nextjs/public/art/`, then tell Claude "art is in".
- **`REVIEW-PROMPT.md` + `review/*.png`:** an independent third UI/UX
  review. Attach the 10 screenshots, paste the prompt, then save the reply
  as `ux/reviews/gemini-r8.md`. The screenshots are regenerated by
  `pnpm --filter @acme/nextjs ux:audit` and aren't committed.

Never paste `.env` contents or API keys into Gemini.
